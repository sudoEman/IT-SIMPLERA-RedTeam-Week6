# IT-SIMPLERA-RedTeam-Week6
A hands-on cybersecurity lab focused on designing and securing an Active Directory environment using Windows Server 2022 and performing basic reconnaissance from Kali Linux.
Active Directory domain and OU design
User and security group management
Shared-folder permissions and access control
Group Policy security configuration
Account management and password security
Basic Nmap network enumeration
DNS reconnaissance using nslookup and dig
Security analysis and remediation recommendations

Environment: Windows Server 2022, Active Directory Domain Services, Kali Linux, Oracle VirtualBox
